# AI Resume Checker & Test Automation

An AI-powered web application that analyzes resumes, validates important information, and provides automated feedback using Python, Flask, SQLite, and OpenAI. The project also includes Java JUnit test cases to demonstrate software testing and quality assurance practices.

---

## Features

- Upload PDF or DOCX resumes
- AI-powered resume analysis
- Resume score generation
- Keyword matching
- Resume validation
- Automated suggestions
- SQLite database
- Java JUnit test cases
- Report generation
